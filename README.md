# 民大丰台·周末出逃指南 🧸🚌✨

> 搞定接驳车，轻松破结界！

「民大丰台·周末出逃指南」是一款 React + Tailwind 打造的涂鸦手账风单页应用：实时查看班车与接驳车、一键抽取组合出逃路线、在便签墙贴上周末心愿，帮丰台同学轻松破结界、说走就走。

## 功能

- 实时班车 / 接驳车时刻表，自动高亮下一班并倒计时
- 一键随机抽取「校区段 + 市区段」组合出逃路线
- 涂鸦便签墙，心愿保存在浏览器本地

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

时刻信息整理自校园班车表与接驳车指南，具体班次以学校最新通知为准。
